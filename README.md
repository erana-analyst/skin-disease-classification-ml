# Skin Disease Classification Using Machine Learning

## 📌 Overview
This project analyzes dermatological data and uses machine learning to classify six skin diseases based on clinical and histopathological features.

## 🎯 Objectives
- Perform Exploratory Data Analysis (EDA).
- Preprocess and analyze the dataset.
- Build and compare machine learning classification models.
- Evaluate model performance using appropriate metrics.
- Explore insights that may support early disease identification.

## 📊 Dataset
The dataset contains 34 attributes, including clinical features, histopathological characteristics, and patient age. The target variable represents six skin disease classes.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## ⚙️ Project Workflow
1. Data loading and preprocessing
2. Exploratory Data Analysis
3. Feature analysis and visualization
4. Machine learning model training
5. Model evaluation and comparison
6. Conclusions and recommendations

## 🚀 How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the `.ipynb` file in Jupyter Notebook.
4. Load the dataset and run the cells in order.
